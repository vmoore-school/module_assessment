# Quiz program
## About
This is the assessment we did for Angela to show the skills she's taught us.

## Usage
To run the program run `python main.py` in your terminal, there shouldn't be any external dependencies (aside from python itself).

## Adding more
To add more questions, you can edit quizzes.py. As long as you follow the format, it should "just work". Each question requires a category, and at least one question with, at least one answer and a marked correct answer. Aside from this, you can add as many questions and possible.
